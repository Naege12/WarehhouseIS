Для начала работы приложения WarehouseIs нужно выполнить эти шаги:

1. Установить PostgresSql или иной сервер.
2. Добавить файл базы данных на сервер. (название - warehouseIs_DB)
3. Перейти в класс Conectdb и ввести путь к бд, пароль и логин от сервера.
4. Все готово к работе!
